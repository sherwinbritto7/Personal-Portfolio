# 🚀 Sherwin Britto — Personal Portfolio

A modern, responsive, and high-performance developer portfolio built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

🌐 **Live Portfolio**: [sherwinb.vercel.app](https://sherwinb.vercel.app/)

---

## ✨ Overview

I'm **Sherwin Britto**, a passionate **Web Developer** based in Mumbai, India. This portfolio showcases my projects, technical stack, work experience, recommendations, and ways to get in touch.

### 🎯 Features
- 🎨 **Modern Aesthetics**: Glassmorphism design system, smooth 3D tilt cards, and dynamic spotlight effects.
- ⚡ **High Performance**: Built with Vite and React for instant page loads and smooth client-side interactions.
- 🎭 **Rich Micro-animations**: Powered by Framer Motion for interactive section reveals, tab switching, and floating particles.
- 📬 **Interactive Contact Form**: Integrated with EmailJS for direct message delivery.
- 📱 **Fully Responsive**: Flawlessly tailored experience across mobile, tablet, and desktop screens.
- 📄 **Data Documentation**: Full compiled portfolio details available in [PORTFOLIO_DATA.md](./PORTFOLIO_DATA.md).
